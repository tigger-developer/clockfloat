## Original body

## Summary

Add a settings window accessible via Shift-click on the floating clock. The window exposes all configurable parameters through a pure AppKit interface.

## Settings to implement

### Font Selection
- macOS `NSFontPanel` integration via "Select Font..." button
- Preview label showing current font name and size
- Separate point-size controls for time and date
- **Migration**: convert existing ratio-of-screen-height defaults to absolute point sizes dynamically on first launch

### Time Format
- 12h / 24h toggle (maps to `"h:mm a"` / `"HH:mm"`)

### Date Format
- Options: `"E d"` (current default), locale short, or custom free-text field

### Late Offset
- On/off toggle + minutes stepper
- Label: "Always late? Wind the clock forward."
- No negative values allowed
- Currently hardcoded as 150 seconds in `Clock.late`

### Opacity
- Single slider controlling both foreground and background
- Text alpha = slider × 0.67 (maintains current visual ratio)

### Hover Behaviour (replaces `dodgesMouse: Bool`)
- Move to opposite corner (current)
- Hide for 5 seconds
- Do nothing (draggable)

### Initial Position (expands `Corner` enum)
- 4 corners + Center Top + Center Bottom

## Files affected
- `Clock.swift` — `ClockConfiguration` overhaul, notification-based reload
- `EvasiveWindow.swift` — expanded positions, hover behaviour modes, opacity param
- `SettingsWindow.swift` — full AppKit settings UI
- `clockfloatTests.swift` — TDD tests for config, enums, migration

## Prerequisites already done
- Shift suppresses mouse dodge (implemented)
- Shift-click opens settings window (implemented)
- Empty `SettingsWindow` scaffolding (implemented)
